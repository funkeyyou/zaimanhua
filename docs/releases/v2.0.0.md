v2.0.0 以「再漫畫X」的新名稱與書頁 X 圖示推出，整合書架和最近閱讀，讓追更與繼續閱讀更直接。

### 書架與閱讀入口

- 書架頂部新增一列最近閱讀，顯示上次章節和頁碼；螢幕越寬，可同時看到的作品越多。
- 最近閱讀與下方訂閱列表各自獨立，同一本漫畫可同時出現；訂閱預設仍按更新時間由新到舊排序。
- 標籤、狀態、閱讀進度和排序收進同一列下拉選單，新增明確的管理按鈕與清除篩選。
- 瀏覽紀錄搬到書架右上方，本機紀錄可離線查看，登入後可查看雲端紀錄。
- 移除「我的」內重複的訂閱和紀錄入口，首頁訂閱預覽的更多按鈕直接開書架。

### 詳情頁與版面

- 「我的」按常用功能、帳號福利、偏好與關於分組。
- 詳情頁提供明確的開始／繼續閱讀按鈕，突出上次章節、頁碼和目前章節。
- 簡介可正確展開全文、收回三行；更多章節按鈕與普通章節使用相同高度、圓角及邊框。
- 寬螢幕主頁使用全寬，開啟詳情且空間足夠時再並排；摺疊、展開與返回時保留路由和捲動位置。
- 漫畫和小說首頁輪播限制高度、保留圖片比例，寬螢幕同時顯示相鄰推薦。

### 安裝與相容性

- Android：下載 `ZAI-X-android.apk` 直接覆蓋安裝，或從 App 內「我的 → 檢查更新」下載。
- Windows：先關閉舊版，下載 `ZAI-X-windows-x64.zip`，解壓到新資料夾後執行 `ZAI-X.exe`。
- 套件識別、簽章、資料目錄和更新來源沿用原設定，保留既有書架、閱讀紀錄與偏好。
- 78 個自動測試通過，MuMu Android 與 Windows 主要介面已驗證；實體摺疊機的完整驗證仍由使用者進行。
