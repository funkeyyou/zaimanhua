# 2026-09-09 介面整理與再漫畫X 品牌

狀態：開發驗證中，尚未發佈新 Release。正式版仍為 v1.9.0。

## 範圍

- 移除「我的訂閱」及「我的」內瀏覽紀錄入口；首頁訂閱預覽的更多入口改開書架。
- 書架第一列展示本機最近閱讀，隨可用寬度增加數量，章節／頁碼隨 Hive 儲存更新。
- 最近閱讀與訂閱互不排除。訂閱預設更新時間降序，其他排序選擇繼續保留。
- 依使用者回饋，全部進度／未讀更新／已追平改成篩選列中的單一下拉選單，節省一列空間。
- 本機瀏覽紀錄從書架右上進入，無網路可用；登入後提供雲端紀錄入口。
- 「我的」依用途分組；詳情頁以閱讀為主要操作，補齊圖示提示文字、章節進度、簡介展開與目前章節強調。
- 主頁以實際可用寬度配置，展開時全寬；有詳情且可用寬度至少 1000 時並排，保留兩側 Widget 與路由。
- Android／Windows 使用新名稱與原創圖示。套件 ID、簽章、Hive 資料名稱、Windows 執行檔名稱及更新端點未更動。
- Windows 的 `ProductName` 保持 `zai_x`：path_provider 2.3.0 用這個欄位組成資料路徑，改名只改視窗標題、FileDescription 與 App 內顯示，避免舊資料看似消失。

## 驗證

- 新增版面測試：360 寬最近閱讀 3 本、1000 寬增加且維持一列、320 寬 1.8 倍文字無溢出。
- 新增資料回歸：保存新頁碼後最近閱讀即更新；閱讀過的作品仍在更新排序訂閱中。
- 新增導覽回歸：1200／400 寬切換、顯示／隱藏詳情均保留捲動位置與 Navigator 堆疊。
- 「我的」涵蓋小螢幕、寬螢幕、簡繁及 1.8 倍文字，並檢查閱讀統計入口仍可觸發。
- Android 打包及 MuMu 操作、Windows CI：待完成後補入結果。
